# 🖥️ OpenList GUI 极速管理大师 (OpenList GUI Manager)

> 基于 Python + CustomTkinter 构建的现代化、功能完备的 OpenList 服务本地管理与配置面板。
> 
> ⚠️ **运行环境限制：本程序仅适用于 Windows 系统。**
> 
> 🔗 **OpenList 开源地址：[OpenListTeam/OpenList](https://github.com/OpenListTeam/OpenList)**

本工具专为 Windows 用户设计，提供一键启停本地 OpenList 服务、实时资源监控、崩溃自动守护、开机自启配置、数据备份与还原、实时日志检索及管理员账号管理等功能，打造专业、极简的图形化运维体验。

---

## ✨ 核心功能

* **💻 服务一键启停**：一键启动、停止或重启 OpenList 服务，窗口退出时自动安全清理后台进程。
* **📊 实时资源监控**：实时获取并刷新 `alist.exe` 服务进程的 **CPU 占用率**、**内存（RAM）消耗** 以及 **累计运行时间（Uptime）**，监控数据每 2 秒更新一次。
* **📥 系统托盘集成**：支持最小化至 Windows 系统托盘（基于 `pystray`）。点击窗口关闭按钮 (X) 时，程序会自动隐藏至系统托盘，保持网盘服务在后台持续运行。右键托盘图标可快速启停服务或彻底退出。
* **🔄 崩溃自动重启**：自带服务守护功能，当检测到 `alist.exe` 进程异常崩溃或意外中止时，管理程序会自动尝试重新启动服务。
* **🚀 开机自启动**：支持一键开启/关闭 Windows 开机自启，直接通过 Windows 注册表进行安全写入，无需手动配置快捷方式。
* **💾 数据一键备份与还原**：
  * **一键备份**：一键将当前的 `config.json` 配置文件和 `data.db`（SQLite 数据库）打包备份至 `backups/` 目录下，并以时间戳命名。
  * **一键还原**：在下拉菜单中选择历史备份目录，一键还原数据（程序会自动停止服务、替换文件并重新启动服务）。
* **🔍 实时日志过滤与导出**：
  * **实时过滤**：在日志输入框中输入关键字，界面会实时过滤并呈现匹配的日志行，大幅提升调试效率。
  * **日志导出**：一键将当前的控制台日志完整保存并导出为本地 `.log` 或 `.txt` 文件。
* **⚙️ 可视化配置编辑**：可视化修改 HTTP 监听端口、监听地址、HTTPS 端口、数据库类型（SQLite3 / MySQL / Postgres）和日志级别，一键保存。
* **🔑 管理员账户管理**：一键执行 `admin` 命令查询初始管理员账号与密码，或在界面输入新密码直接重置。

## 🚀 快速开始

### 1. 运行环境准备

本程序**仅适用于 Windows 系统**，且需要 Python 3.10 或更高版本。

#### 基础依赖安装：
```bash
pip install customtkinter
```

#### 可选依赖安装（推荐）：
* **系统托盘支持**（安装后方可启用最小化到托盘功能，若未安装程序会安全降级为普通窗口关闭行为）：
  ```bash
  pip install pystray Pillow
  ```
* **高精度资源监控**：
  * 程序默认已集成 `psutil` 高精度监控。如果您的系统中没有安装，程序会自动平滑降级为使用 Windows 原生 `tasklist` 命令行解析内存数据。

### 2. 运行管理程序

1. 在 `GUI` 目录下，运行以下命令启动图形化管理面板：
   ```bash
   python app.py
   ```
2. 启动后，在界面中指定/选择您的 `alist.exe` (或 `openlist`) 主程序路径即可（支持通过右侧 **“浏览...”** 按钮手动选择任意路径下的可执行程序）。

## ⚠️ 常见问题与注意事项

1. **端口冲突**：如果服务启动后立即闪退，且日志中提示端口占用，请前往 **“配置编辑”** 选项卡将 HTTP 监听端口修改为其他未占用的端口（例如 `5245`），保存后重新启动服务。
2. **数据库文件锁定**：当 OpenList 服务处于运行中状态时，数据库文件可能会被服务进程独占锁定。此时在 **“管理员命令”** 中查询或重置密码可能会失败。**建议先停止服务，再进行密码查询或重置操作，完成后重新启动服务。**
3. **彻底退出**：如果启用了系统托盘功能，点击主窗口的关闭按钮会将程序隐藏至托盘。要彻底关闭管理程序及 OpenList 服务，请右键点击任务栏右下角的托盘图标，选择 **“彻底退出”**。
